# Project instructions

Read [HANDOFF.md](HANDOFF.md) before starting work. Use it to understand the current state and record changes for the next contributor. Follow its pre-commit rules for every commit, and include the matching handoff entry in that commit.

Get the user's explicit authorization before committing or pushing. Bring technical decisions that need the user's input to them with a recommendation and rationale. Use [GAME_VISION.md](GAME_VISION.md) and [TECHNICAL_DECISIONS.md](TECHNICAL_DECISIONS.md) for the approved game and technical direction.
